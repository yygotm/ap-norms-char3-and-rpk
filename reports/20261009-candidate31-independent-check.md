## 独立検査器の方法と確認範囲

`header.txt` の多項式から F₃[x]/(f) を構成し、係数配列による畳み込み・f による剰余・二進法のべき乗を自作した。M を試し割りで素因数分解し、x^M=1 かつ全素因数 p に対して x^(M/p)≠1 を確認する。これにより商環の非零元がすべて x の冪であり、商環が体であることも従う。検査済みの2組の素因数は (3,6): 2,7,13、(27,6): 2,7,13,19,37,757。

各証人では α=x^i、β=x^j、α+β を自作の演算で構成し、α および α+β の原始性を M の各素因数によるべき乗で、両ノルムを M/(q−1) 乗で確かめる。正規性は、F_q の F₃ 基底 `1,g_q,…,g_q^(k−1)` を用い、`b_l α^(q^i)` の N×N 行列を F₃ 上で行基本変形して階数 N かどうか判定した。α または α+β の片方が正規ならよい。これは依頼書に例示された、F_q 上の共役行列の階数に相当する独立の判定法である。

軌道被覆は、各代表 j から `3^t j mod M` と `3^t j+M/2 mod M`（0≤t<N）をビット集合に立て、全 M 個の指数の被覆と代表の重複を調べる実装である。**実行したのは (3,6) のみ**で、他組の被覆状況は不明。

再実行例：`python ap-norms/gpt-check/verify.py <certificate dir>/3_6`。速度測定は末尾に `--pairs 50` を指定した。(27,6) はこの抜き取りだけを実行した。

## 数学的な還元と原典確認

β→β³ は絶対フロベニウスである。証人 α→α³ により原始性を保ち、F_q 上の正規性も半線形自己同型により保つ。ノルムは N(α³)=N(α)³ となり、F_q の原始元の組の集合を全単射で置換する。β→−β は証人 α→α+β として2項を交換すればよく、指定ノルムの順序も交換される。したがって「全 β・全順序付き原始ノルム対」という性質は両操作で保存される。実際の証明書がこれらの全軌道を代表しているかは、上表の検査範囲に限る。

q=3 では F₃ の原始元は −1 だけである。F_{3^n} の原始元 α=g^i の i は偶数 M=3^n−1 と互いに素なので奇数であり、N(α)=α^(M/2)=(g^(M/2))^i=−1。したがって両項の原始性があれば指定ノルム条件は自動的に満たされる。[Chatterjee–Sharma–Shukla–Tiwari, arXiv:2401.01819, Theorem 5.7](https://arxiv.org/pdf/2401.01819) は q=3,n=9,16 を例外候補に含む。一方、[Lemos–Neumann–Ribas, arXiv:2208.02876, Theorem 1.1(i) と Table 6](https://arxiv.org/pdf/2208.02876) はノルム指定なしの原始・片方正規な2項について、表6の候補を除き任意の非零 β で存在を保証する。表6には (3,9) と (3,16) がない。先述の q=3 の観察と合わせると、**この2組は 𝒮₂ に入る**という判断は正しい。ただし Lemos らの論文が直接「ノルム指定あり」と記しているわけではなく、この追加は q=3 に限る推論である。

## 限界

この報告は8組すべての証明書の全件検査ではない。特に最大の (27,6) では50/1,549,845,936 組しか見ておらず、軌道被覆も未実行である。速度外挿は純 Python 実装の先頭50件に基づき、別言語・事前計算・並列化による高速化の限界を示すものではない。依頼の2時間停止条件の下で、この実装をそのまま全件実行しない根拠として用いた。
